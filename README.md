# OneInput

**Enter once. Copy everywhere.**

A browser-only prototype for turning a few inputs into multiple deterministic production-ready outputs.

## Prototype workflows
- New Project
- New Product
- New Campaign

## Principles
- No API
- No backend
- No account
- No uploads
- No AI dependency
- All transformations run locally in the browser

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server.

## Next validation
Test whether users immediately understand the value and whether the custom recipe builder should become the core product.
